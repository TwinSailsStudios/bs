# Survival Guide

The `func` incantations are commands, not code: in the Terminal IDE they are
typed as a line and never enter your file. In the Web IDE most have buttons.

## Incantations

| Incantation | Effect | Notes |
|-------------|--------|-------|
| `func holywater tg: fire` | Temperature −40% | Blocked while frozen |
| `func coal` | Temperature +40% | The ONLY input accepted while `[FROZEN]` |
| `func shield` | Survive a solar flare | Only works inside the 3-second window |
| `func exorcise tg: ghost` | Revert all ghost commits | Safe to cast speculatively |
| `func compile` | Translate to Python and run | The whole point |
| `func quit` | Exit, saving the file | Terminal IDE only; the one safe exit |

## Doctrine of the Survivors

1. **Write short programs.** Instability has no remedy. Every line is +2%
   forever. Plan to be done before line 20.
2. **Never edit upward.** The pillars live in your committed lines. If a
   previous line is wrong, it is now a load-bearing mistake. Route around it
   with new code.
3. **Cool on a schedule, not on a feeling.** +5%/line means holy water every
   eight lines holds you near 50%. Below 10% you freeze, and thawing costs a
   `func coal` you'll regret at 90%.
4. **Spell-check before Enter.** One transposed letter in `manifest` costs
   you a 50-character ransom and, statistically, several lines of code.
5. **Exorcise before every compile.** Ghost commits are silent. If you've
   been in the editor more than 60 seconds, assume at least one of your
   conditionals is lying. `func exorcise tg: ghost` is free when innocent.
6. **Read your quotes aloud.** The Memory Demon gives you 5 seconds. Saying
   it engages a second memory channel. The wiki takes no responsibility for
   how this looks in an open-plan office.
7. **Learn to touch-type.** Solar flare failure means 30 seconds of coding
   blind. The buffer is fine. You are the problem.
8. **`suffer`, never `while`.** One is a keyword. The other is dairy.
9. **Compile early.** A program that has already run successfully exists in
   the universe even if the file doesn't anymore.
10. **In the Web IDE, save often.** Download the `.bs` file. localStorage is
    autosaved, but Damnation Mode deaths consume the autosave too. Disk is
    outside the demon's jurisdiction.
